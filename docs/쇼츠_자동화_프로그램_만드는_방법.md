# 🎬 유튜브 쇼츠 자동화 프로그램 만드는 방법

아이디어 **한 줄**만 입력하면 👇

> 제목 5개 → 대본(10~12장면) → 이미지 → 음성(TTS) → 자막 → 영상 → 유튜브 비공개 업로드

까지 자동으로 돌아가는 프로그램을 만드는 방법입니다.
전부 무료 API만 사용해도 만들 수 있습니다.

---

## 0. 준비물

- Windows PC (Mac도 가능)
- Python 3.10 이상 — https://www.python.org
- FFmpeg (영상 합성에 필수)
- API 키 2개 (Gemini, 구글 OAuth — 아래 2번에서 발급)

## 1. 전체 구조 — 파이프라인 5단계

```
① 아이디어 → Gemini API로 제목 5개 / 설명 / 대본 생성 (10~12장면)
② 장면별 이미지 생성 (로컬 GPU — SDXL-Turbo 또는 SD 3.5 Large Turbo)
③ 장면 대사 → Edge TTS로 음성 mp3  ← 무료! API 키 불필요 (MS 신경망 목소리)
④ FFmpeg로 합성: 이미지 슬라이드쇼 + 내레이션 + 자막(ASS) → 쇼츠 규격(1080x1920)
⑤ YouTube Data API v3로 유튜브 비공개 업로드
```

**핵심 포인트**: 각 장면의 표시 시간을 **"그 장면 음성 길이"와 똑같이** 맞추면
영상·음성·자막이 딱 맞습니다. 이것만 지키면 실패가 없습니다.

## 1-1. 🧠 사용 모델 정리 (전부 무료로 가능)

| 단계 | 모델/도구 | 무료 여부 | 어디서 발급/다운로드 |
|---|---|---|---|
| ① 대본·제목 생성 | **Gemini 2.5 Flash** (API) | 무료 할당 | https://aistudio.google.com |
| ② 이미지 생성 | **SDXL-Turbo** 또는 **SD 3.5 Large Turbo** (로컬 GPU) | **완전 무료 (무제한)** | https://huggingface.co/stabilityai |
| ③ 음성 생성 | **Edge TTS** (MS 신경망) | 완전 무료, **키/계정 불필요** | `pip install edge-tts` |
| ④ 영상 합성 | **FFmpeg** | 오픈소스 무료 | https://www.gyan.dev/ffmpeg/builds/ |
| ④ GPU 인코딩 | **NVENC** (NVIDIA 카드 내장) | 무료 | NVIDIA 드라이버 + FFmpeg |
| ⑤ 유튜브 업로드 | **YouTube Data API v3** | 무료 (쿼터 내) | https://console.cloud.google.com |

**이미지 생성 — 로컬 Stable Diffusion 2종 (둘 중 선택, 둘 다 무료·무제한):**

⚠️ Gemini API는 **무료 티어에서 이미지 생성이 안 됩니다** (텍스트 생성만 가능).
이미지는 **로컬 GPU에서 SD 모델로 직접 생성**하는 방식입니다.

- **SDXL-Turbo** — 빠르고 가벼움 (GTX 1080Ti에서 **장당 약 43초**)
  - https://huggingface.co/stabilityai/sdxl-turbo
  - `diffusers` 폴더 형태: `AutoPipelineForText2Image.from_pretrained("stabilityai/sdxl-turbo")`
  - 4스텝 생성, `guidance_scale=0.0` 필수
- **SD 3.5 Large Turbo** — 더 고품질 (Q4 양자화 GGUF로 1080Ti에서 **장당 약 31초**, 8스텝)
  - https://huggingface.co/stabilityai/stable-diffusion-3.5-large-turbo
  - GGUF 양자화 파일 사용 (Q4_K_M 등): https://huggingface.co/city96/stable-diffusion-3.5-large-turbo-GGUF
  - `StableDiffusion3Pipeline.from_single_file(...)` — transformer만 GGUF, CLIP/VAE는 HF에서 자동 다운로드
- 공통: **VRAM 8GB+ 권장** (1080Ti 11GB에서 두 모델 모두 동작 확인), `pip install diffusers torch`

**캐릭터 고정 + 말풍선 — 만화 일관성의 핵심:**
- 주인공 캐릭터를 정하면(기본 **너구리**) SD 프롬프트 **맨 앞에 영어 캐릭터 토큰을 고정** →
  12장 전부 동일 캐릭터 유지. 예) `a cute chubby korean raccoon character, brown fur mask, orange necktie,`
- 대사 말풍선은 **SD가 아니라 PIL로 직접 그립니다** — SD가 한글을 그리면 거의 100% 외계어가 됨.
  이미지는 `no text`로 생성하고, 완성된 PNG 위에 흰 말풍선(검정 테두리+꼬리)을 그려 대사를 얹음
  → 한글은 항상 선명 + 만화 느낌 강화 + "진짜 같은 AI 이미지" 회피(AI 라벨 방지에도 유리)

**음성 생성**: Edge TTS는 엣지 브라우저의 MS 신경망 목소리를 무료로 쓰는 방식 —
`ko-KR-SunHiNeural`(여성) / `ko-KR-InJoonNeural`(남성). API 키도 계정도 필요 없습니다.
대안: gTTS(무료·품질 낮음), ElevenLabs(유료·고품질).

**영상 합성**: FFmpeg가 실제 "영상 편집기" 역할을 합니다 (이미지→슬라이드쇼, 음성 합성,
자막 굽기, 배속 조절, 인코딩). Windows용 다운로드:
- https://www.gyan.dev/ffmpeg/builds/ (9.x 최신 — 최신 GPU 권장)
- https://github.com/BtbN/FFmpeg-Builds/releases (8.x — 구형 GPU의 NVENC 호환용, 1080Ti 확인됨)

## 2. API 키 발급 (무료)

**① Gemini API** (대본·제목·설명 텍스트 생성 — 이미지는 로컬 SD 모델이 담당)

**② YouTube 업로드용 OAuth** (구글 클라우드)
- https://console.cloud.google.com → 프로젝트 생성
- **"YouTube Data API v3" 검색 → "사용" 클릭** ⚠️ 안 하면 업로드 때 403 에러!

- JSON 다운로드 → `client_secret.json`으로 이름 변경 → 프로젝트 폴더에 저장

## 5. 핵심 코드 스니펫 (실제 검증된 방식 그대로)

### ① 대본 생성 — modules/text_gen.py

```python
import google.generativeai as genai

genai.configure(api_key=GEMINI_API_KEY)
model = genai.GenerativeModel("gemini-2.5-flash")   # 최신 모델명으로

PROMPT = """다음 아이디어로 60초 분량의 유튜브 쇼츠 대본을 작성해줘.
- 10~12개 장면으로 나누기 (각 장면 5~6초)
- 대사에는 영어, 특수문자, 이모지 사용 금지 (숫자와 한글만)
형식:
[장면 1] (0~5초)
- 내용: 실제로 읽어줄 대사
- 시각: 이미지 생성용 상세 묘사

아이디어: {idea}"""

text = model.generate_content(PROMPT.format(idea=아이디어)).text
# "[장면 N]" 블록을 파싱해서 [{"content": 대사, "visual": 묘사}, ...] 리스트로 저장
```

### ② 장면별 이미지 생성 (로컬 SD 모델 — 무료·무제한)

⚠️ Gemini 무료 API로는 이미지 생성이 불가 → 이미지는 로컬 GPU의 SD 모델로 생성 (2종 중 선택)

```python
# ── SDXL-Turbo: 빠르고 가벼움 (1080Ti 기준 장당 약 43초) ──
# pip install diffusers torch  →  처음 실행 시 Hugging Face에서 자동 다운로드(약 7GB)
from diffusers import AutoPipelineForText2Image
import torch

pipe = AutoPipelineForText2Image.from_pretrained(
    "stabilityai/sdxl-turbo", torch_dtype=torch.float16).to("cuda")
img = pipe(prompt, num_inference_steps=4, guidance_scale=0.0).images[0]
img.save("scene_01.png")    # 터보 모델은 4스텝 (guidance_scale=0.0 필수!)

# ── SD 3.5 Large Turbo: 더 고품질 (GGUF Q4 양자화, 1080Ti 기준 장당 약 31초) ──
# 모델: https://huggingface.co/city96/stable-diffusion-3.5-large-turbo-GGUF
#       transformer만 GGUF로 로드하고 CLIP/VAE는 HF에서 자동 다운로드됨
from diffusers import SD3Transformer2DModel, StableDiffusion3Pipeline
from diffusers.quantizers import TransformersBridge  # gguf 지원용

transformer = SD3Transformer2DModel.from_single_file(
    "sd3.5_large_turbo-q4_k_m.gguf", torch_dtype=torch.float16)
pipe = StableDiffusion3Pipeline.from_pretrained(
    "stabilityai/stable-diffusion-3.5-large-turbo",
    transformer=transformer, torch_dtype=torch.float16).to("cuda")
img = pipe(prompt, num_inference_steps=8, guidance_scale=0.0).images[0]
img.save("scene_01.png")
```

**말풍선 삽입 — PIL로 직접 그리기 (SD에 글자를 맡기면 외계어가 나오므로 필수 기법!):**

```python
# 이미지는 "no text" 프롬프트로 생성 → 완성된 PNG 위에 말풍선+대사를 얹는다
from PIL import Image, ImageDraw, ImageFont

def add_speech_bubble(path, text, size=52):
    img = Image.open(path).convert("RGB"); W, H = img.size
    d = ImageDraw.Draw(img); ink = (20, 20, 20)
    font = ImageFont.truetype("C:/Windows/Fonts/malgun.ttf", size)   # 맑은 고딕
    max_w = int(W * 0.86)                        # 말풍선 최대 폭
    lines, line = [], ""                         # 글자 단위 줄바꿈
    for ch in text:
        if line and d.textlength(line + ch, font=font) > max_w - 90:
            lines.append(line); line = ch
        else:
            line += ch
    if line: lines.append(line)
    tw = max(int(d.textlength(l, font=font)) for l in lines)
    lh = size + 16
    bw, bh = tw + 90, lh * len(lines) + 50
    x0, y0 = (W - bw) // 2, int(H * 0.035)       # 상단 중앙 배치
    d.rounded_rectangle([x0, y0, x0 + bw, y0 + bh], radius=int(size * 0.8),
                        fill="white", outline=ink, width=7)
    cx = W // 2                                  # 꼬리 (캐릭터 쪽 = 아래)
    d.polygon([(cx - 45, y0 + bh - 1), (cx + 45, y0 + bh - 1), (cx, y0 + bh + 85)], fill="white")
    d.line([(cx - 45, y0 + bh - 1), (cx, y0 + bh + 85), (cx + 45, y0 + bh - 1)], fill=ink, width=7)
    ty = y0 + 25
    for l in lines:                              # 대사 렌더링
        d.text(((W - int(d.textlength(l, font=font))) // 2, ty), l, font=font, fill=ink)
        ty += lh
    img.save(path)

add_speech_bubble("scene_01.png", "안녕하세요! 오늘은 파이썬으로 쇼츠를 만들어볼거예요!")
```

### ③ 음성 생성 — modules/tts.py (Edge TTS, 무료·API 키 불필요)

```python
import asyncio
import edge_tts

async def make_voice(text: str, out: str):
    await edge_tts.Communicate(text, "ko-KR-SunHiNeural").save(out)
    # 남자 목소리는 "ko-KR-InJoonNeural"

asyncio.run(make_voice("안녕하세요! 오늘은 파이썬 자동화...", "output/audio/scene_01.mp3"))
```

### ④ 음성 길이 측정 — 영상-음성 동기화의 핵심

```python
import subprocess

def duration_of(path: str) -> float:
    r = subprocess.run(
        ["ffprobe", "-v", "error", "-show_entries", "format=duration",
         "-of", "default=noprint_wrappers=1:nokey=1", path],
        capture_output=True, text=True)
    return float(r.stdout.strip())
```

### ⑤ 영상 합성 — modules/video_edit.py

장면 목록 파일(image_list.txt) 작성:

```
file 'scene_01.png'
duration 4.60
file 'scene_02.png'
duration 4.87
... (장면 수만큼 반복)
file 'scene_12.png'   ← 마지막 장면은 한 번 더 씀 (FFmpeg concat 규칙)
```

합성 명령 (자막 포함):

```bash
ffmpeg -y -f concat -safe 0 -i image_list.txt -i narration.mp3 ^
  -vf "scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2,fps=30,ass=subtitles.ass" ^
  -c:v h264_nvenc -cq 23 -c:a aac -b:a 192k -shortest final.mp4
```

- GPU가 없으면 `-c:v h264_nvenc -cq 23` → `-c:v libx264 -crf 23` 로 교체
- **1.2배속 만들기**: 장면 duration을 전부 ÷1.2 하고, 음성에 `-af atempo=1.2` (피치 유지 — 유튜브 재생속도와 같은 방식. 영상만 빨리 하면 음성과 어긋남!)
- 자막(ASS): 대사마다 시작~끝 구간을 만들어 `subtitles.ass` 파일로 저장 → `ass=` 필터로 굽기
  - 스타일 예: 맑은 고딕 60pt, 흰 글자 + 검은 외곽선, 하단 중앙 (Alignment=2, MarginV=90)
  - 긴 문장은 24자에서 2줄로 분할 (\N)

### ⑥ 유튜브 비공개 업로드 — modules/youtube_upload.py

```python
from google_auth_oauthlib.flow import InstalledAppFlow
from googleapiclient.discovery import build
from googleapiclient.http import MediaFileUpload

SCOPES = ["https://www.googleapis.com/auth/youtube.upload"]
flow = InstalledAppFlow.from_client_secrets_file("client_secret.json", SCOPES)
creds = flow.run_local_server(port=0)      # 첫 1회만 브라우저 로그인 → 토큰 저장해두면 이후 자동
yt = build("youtube", "v3", credentials=creds)

body = {
    "snippet": {"title": title[:100], "description": desc[:5000], "categoryId": "22"},
    "status": {"privacyStatus": "private", "selfDeclaredMadeForKids": False},
}
media = MediaFileUpload("final.mp4", mimetype="video/mp4", resumable=True)
res = yt.videos().insert(part="snippet,status", body=body, media_body=media).execute()
print("업로드 완료:", f"https://www.youtube.com/watch?v={res['id']}")

# 업로드 직후 실제 반영 확인 (역조회)
chk = yt.videos().list(part="status", id=res["id"]).execute()
print("공개설정:", chk["items"][0]["status"]["privacyStatus"])   # private 나오면 정상
```

## 6. 꿀팁 & 트러블슈팅 (직접 겪은 것들)

- ⚠️ **유튜브 AI 공개 라벨** ("수정 또는 합성된 콘텐츠") — "실제 없는 일이 **진짜처럼 보이는** 장면"을 만들었을 때만 공개 의무가 있음.
  **명백한 웹툰/만화 스타일은 공개 대상이 아님** → 이미지가 실사처럼 나오지 않도록 스타일 프롬프트를 유지하세요
  (이 프로그램은 `_build_sd_prompt`에 웹툰 스타일 토큰 내장 — SD 3.5가 실사 쪽으로 가면 화풍 토큰을 더 강화)
- ⚠️ 업로드가 **403 "accessNotConfigured"** → Google Cloud에서 **YouTube Data API v3를 "사용" 안 한 것**. 제일 많이 막히는 지점!
- ⚠️ "비공개로 했는데 비공개가 아니에요" → 업로드 직후 역조회(videos().list)로 확인하고, 그래도 이상하면 **로그인한 구글 계정과 확인한 채널이 같은지** 체크 (다른 계정의 채널에 올라가는 경우가 있음)
- 영상-음성 어긋남 → 장면 표시시간 = 장면 음성 길이(ffprobe 측정값) 1:1 매칭
- 배속은 **음성 atempo + 장면 duration 나누기** 세트로 (영상만 빨리 하면 싱크 깨짐)
- 쇼츠 규격: 1080x1920, 30fps, 60초 이하
- 장면 사이에 0.5초 무음을 넣으면 호흡이 자연스러움
- 이미지 프롬프트에 `no text` 명시 → 글자는 SD가 아니라 **PIL 말풍선**으로 (한글 깨짐 방지)
- 주인공 캐릭터 토큰을 프롬프트 **맨 앞에 고정**하면 12장 전부 동일 캐릭터 유지 (예: 너구리)
- 대사에 영어/특수문자/이모지 금지 (TTS 발음 오류 방지)
- 첫 업로드는 반드시 **비공개(private)**로 테스트 → 확인 후 공개 전환
- NVENC(GPU 인코딩) 안 되면 드라이버↔FFmpeg 버전 호환 문제. 안 되면 libx264(CPU)도 품질 동일하게 잘 됩니다

> 프로젝트: 유튜브 쇼츠 자동화 (<project>)
> 사용 모델: `qwen/qwen3.8-27b` (Groq 무료 티어, on_demand)

## 1. Groq 무료 티어 한도 (실측)

| 항목 | 한도 | 실측 에러 |
|---|---|---|
| **OTPM** (분당 출력 토큰) | **1,000** | 429 `output tokens per minute (OTPM): Limit 1000` |
| 요청 `max_tokens` | 한도 이하로 지정해야 함 | 4096 지정 시 429 즉시 거부 |
| 모델당 TPM/RPM | 모델·티어별 상이 | 조직(org) 단위로 적용됨 |
| 추론 모델 | qwen 계열은 '생각' 토큰이 출력에 포함됨 | 추론 켜면 실제 답변 가용 토큰 감소 |

### 발생했던 에러 3종

1. **404 `model_not_found`**
   - `llama-3.3-70b-versatile` 등 예전 모델 ID는 Groq에서 삭제됨
   - → **실행 시마다 `/models` 실시간 목록 조회로 해결** (`list_groq_models()`)

2. **429 `Request too large ... OTPM: Limit 1000`**
   - `max_tokens: 4096` 요청이 분당 출력 한도 1,000 초과로 거부
   - → `max_tokens: 900` 안전치 + **429 시 60초 대기 후 자동 재시도 3회** (Retry-After 헤더 존중)

3. **대본 잘림 (출력이 중간에 뚝 끊김)**
   - 원인 3중: ① qwen 추론 토큰이 한도를 먹음 ② 장면당 시각 묘사가 ~150-180 토큰 ③ 12장면 1회 요청이 ~2,000 토큰 필요
   - → 아래 2번 참고

## 2. 적용한 개선 방안 (modules/text_gen.py)

### 2-1. 추론(생각) 끄기 — qwen 계열

```
프로브 테스트 결과 (scripts/test_reasoning.py):
  reasoning_effort: 'none'   → 200 OK ✅
  reasoning_format: 'hidden' → 200 OK ✅
  enable_thinking: false     → 400 거부 ❌
```

- `__init__`에서 모델명에 `qwen` 있으면 `extra_payload = {'reasoning_effort': 'none'}` 자동 첨부
- 호출 시 400 뜨면(미지원 모델) 옵션 자동 제거 후 1회 재시도

### 2-2. 요청 크기 축소 + 429 자동 재시도

- Groq 요청 `max_tokens`: 4096 → **900**
- 429 뜨면 크래시 대신 `⏳ 할당량 초과(429) → N초 후 자동 재시도 (1/3)` 표시 후 대기·재시도

### 2-3. 대본 2단계 분리 + 분할 호출 (핵심 개선)

**이전 방식 (잘림 발생):**
```
12장면 (내용+시각 한번에) = 1회 호출, ~2,000 토큰 필요 → 1,000 한도 초과 → 잘림
```

**개선 방식 (적용됨):**
```
[1/2] 대사(내용)만 생성 : 6장면씩 2회 호출  (회당 ~400-500 토큰)
[2/2] 시각(묘사)만 생성 : 6장면씩 2회 호출  (회당 ~400-500 토큰)
  ↳ 빈 장면 있으면 1회 자동 보충 요청
총 4~5회 호출, 회당 모두 1,000 토큰 이하 → 잘림 없음
```

- 호출 횟수가 늘어도 **회당 출력이 작아서 한도에 안 걸림** (분당 기준이므로 호출 사이가 짧으면 429 재시도로 통과)
- 확정된 대사를 시각 생성 프롬프트에 그대로 넣어 일관성 유지

### 2-4. 시간 균등 배분

- 이전: 모델이 시간을 맡김 → 35~40초 건너뛰거나 빈 시간 발생
- 개선: **장면 번호로 균등 배분** (`_time_range()`): 12장면 × 5초 = `0~5초` ... `55~60초`

### 2-5. 실시간 모델 목록 조회

- `list_groq_models()`: 실행마다 `/models` 조회 → TTS/guard/embed 등 비대화형 모델 자동 제외
- 예전 모델 ID 삭제 문제(404) 원천 차단, 목록에서 번호 선택

## 4. 남은 주의사항

| 주의 | 내용 |
|---|---|
| 제목+설명 연달아 호출 | 2회 연속 요청이라 분당 한도 걸릴 수 있음 → 재시도로 통과되지만 느림 |
| 한자 섞임 | qwen이 가끔 한자 섞어 출력 (`퇴근前要`) → TTS 특수문자 필터로 걸러지고, 승인 단계에서 문구 수정 가능 |
| 모델 교체 시 | 429가 잦으면 모델 선택에서 다른 번호 (예: `openai/gpt-oss-120b`)로 교체 |
| max_tokens 900 | 답변 1개(제목 5개 등)는 충분. 만약 장문 요청 필요하면 Groq 대신 Gemini/OpenRouter 사용 |

# 🗺️ YouTube 자동화 SaaS — 한눈에 보기 (컨셉 · 구조도 · 파일트리)

> **컨셉**: 아이디어 한 줄 입력 → 유튜브 쇼츠 완성·업로드까지 원클릭 (수동 3시간 → 10분)
> **원칙**: 무료 API 우선 + 로컬 AI 폴백 — 쿼터·과금 걱정 없이 끝까지 감
> **상태**: 전 파이프라인 실사용 가능 (`python main.py`) · 갱신 2026-09-16

---

## 🔁 5단계 파이프라인

```
아이디어 → ① 제목/설명/대본 → ② 이미지 12장 → ③ 나레이션 → ④ MP4 편집 → ⑤ 유튜브 업로드
          Gemini→OR→Groq     ★SD3.5 31초/장   Edge TTS     MoviePy      OAuth
                                            (gTTS 폴백)
```
- 각 단계 체크포인트 저장 → 중단해도 이어하기
- 한글 프롬프트는 로컬 SD용으로 자동 영어 번역 (Groq→OpenRouter 폴백)

---

## 🌳 파일 트리 (전체 구조도)

```
<project>\
│
├─ 📄 main.py ────────────────── 원클릭 실행·5단계 흐름·시작메뉴(이어하기)   ★시작점
├─ 📄 config.py ──────────────── API 키 + 모델 경로/스텝 (SD_DEVICE=cuda, SD_STEPS=8)
├─ 📄 requirements.txt ───────── 패키지 목록
│
├─ 📁 modules\ ───────────────── 단계별 기능 모듈
│   ├─ text_gen.py ──────────── ① 제목·설명·대본 (3 API 순차 폴백)
│   ├─ image_gen.py ─────────── ② 이미지 3방식 분기 + _load_sd_gguf()      ★핵심
│   ├─ tts.py ───────────────── ③ Edge TTS 나레이션 (gTTS 폴백)
│   ├─ video_edit.py ────────── ④ 장면-음성 동기화 맞춰 MP4 합성
│   └─ youtube_upload.py ────── ⑤ OAuth 업로드 (공개/비공개/나중에)
│
├─ 📁 scripts\ ───────────────── 다운로더·테스트·패치 유틸
│   ├─ gguf_patch.py ────────── SD3.5 GGUF 로드 패치 (QK-norm 디퀀타이즈)  ★★★핵심패치
│   ├─ download_q4.py 등 ────── 모델 다운로더 (이어받기 지원)
│   └─ test_*.py / verify_*.py ─ 단계별 검증 스크립트
│
├─ 📁 model\ ─────────────────── 로컬 AI 모델
│   ├─ sd3.5_large_turbo-q4_k_4_0.gguf ── 4.9GB  ★메인 (31초/장, 오프라인)
│   └─ sdxl-turbo\ ──────────── 13.2GB 대안 (43초/장, 하단 아티팩트 있음)
│
├─ 📁 output\ ────────────────── 결과물
│   ├─ images\ / videos\ / audio\   ← 장면 PNG / 최종 MP4 / MP3
│   ├─ checkpoint.json ──────── 이어하기용
│   └─ script.txt / titles.txt ─ 단계별 저장 파일 (복구용)
│
├─ 📁 venv\ ──────────────────── 파이썬 가상환경 (torch 2.5.1+cu118 고정 — 업그레이드 금지)
│
└─ 📄 문서: 개발컨셉.md(이 파일) · 사용법_설명서.md · SD3.5_Large_Turbo_설정보고서.md
           · 프로젝트_진행_내역.md · GPU/SDXL/OAuth/OpenRouter 세팅 가이드
```

> 루트의 `*.bak_*`, `*_log.txt`, `tmp_*.py` 등은 개발 잔재 — 삭제해도 무방합니다.

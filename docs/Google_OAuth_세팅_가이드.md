# Google OAuth 세팅 가이드 (유튜브 업로드용)

영상 제작은 이미 성공했고, **유튜브 업로드만 구글 인증이 필요**해.
아래 순서대로 하면 10분 안에 세팅 완료된다.

---

## 1단계. Google Cloud 프로젝트 만들기

1. 브라우저에서 접속: https://console.cloud.google.com
2. 구글 계정으로 로그인 (업로드할 유튜브 채널의 구글 계정 추천)
3. 상단 프로젝트 선택 클릭 → **"새 프로젝트"**
4. 프로젝트 이름: `youtube-shorts-auto` (아무거나 OK)
5. 만들기 → 몇 초 후 프로젝트 생성됨 → 선택

---

## 2단계. YouTube Data API 사용 설정

1. 좌측 메뉴(☰) → **API 및 서비스 → 라이브러리**
2. 검색창에 `YouTube Data API v3` 입력
3. 클릭 → **사용** 버튼 클릭

---

## 3단계. OAuth 동의 화면 설정

1. 좌측 메뉴 → **API 및 서비스 → OAuth 동의 화면**
2. User Type: **외부(External)** 선택 → 만들기
3. 앱 정보 필수 항목만 채우기:
   - 앱 이름: `YouTube Shorts Auto`
   - 사용자 지원 이메일: 본인 이메일 선택
   - 개발자 연락처: 본인 이메일
4. 그대로 다음 → 다음 → **테스트 사용자** 화면에서:
   - **+ ADD USERS** → 본인 구글 이메일 추가 (⚠️ 이거 안 하면 로그인 차단됨)
5. 저장

---

## 4단계. OAuth 클라이언트 ID 만들기 (client_secrets.json 발급)

1. 좌측 메뉴 → **API 및 서비스 → 사용자 인증 정보**
2. 상단 **+ 사용자 인증 정보 만들기 → OAuth 클라이언트 ID**
3. 애플리케이션 유형: **데스크톱 앱** 선택
4. 이름: `desktop-client` (아무거나) → **만들기**
5. 생성된 항목에서 **JSON 다운로드** 클릭
6. 다운로드한 파일을 이 이름으로 변경: `client_secrets.json`
7. 이 위치로 이동:

```
<project>\client_secrets.json
```

---

## 5단계. 프로그램에서 로그인

이제 프로그램 실행 → 업로드 선택하면:

```
🌐 브라우저에서 구글 로그인 창을 엽니다...
```

- 브라우저가 자동으로 열림 → **업로드할 유튜브 채널의 구글 계정**으로 로그인
- "Google에서 확인되지 않은 앱" 경고가 뜨면:
  → 좌하단 **고급** → **(앱 이름)로 이동(안전하지 않음)** 클릭 → 허용
- 권한 승인 체크 → 허용
- 완료되면 `token.pickle`이 저장되고 **다음부터는 자동 로그인** (브라우저 안 뜸)

---

## ⚠️ 알아둘 제한사항 (중요)

| 항목 | 내용 |
|---|---|
| **토큰 유효기간** | 테스트(사내 테스트) 모드 앱은 **7일마다 토큰 만료** → 만료되면 브라우저 로그인 다시 1회 (7일마다 재로그인 필요) |
| **업로드 영상 잠금** | OAuth 검증 안 된 앱으로 업로드한 영상은 **"비공개 잠금(locked private)"** 상태로 시작됨 → 유튜브 스튜디오에서 직접 공개 전환 불가. 이건 구글 정책이라 어쩔 수 없음. 정식 공개 업로드를 자동화하려면 나중에 OAuth 검증(verification) 심사 필요 |
| **쿼터** | 영상 업로드 1회 = 1,600 쿼터 / 하루 기본 10,000 쿼터 → **하루 약 6개까지 업로드 가능** |
| **채널** | 로그인한 구글 계정의 **현재 활성 채널**로 올라감. 채널이 여러 개면 로그인 전에 올바른 채널이 활성인지 확인 |

---

## 문제 해결

| 증상 | 해결 |
|---|---|
| `access_denied` / 로그인 차단 | 3단계의 **테스트 사용자**에 본인 이메일 추가했는지 확인 |
| `invalid_grant` | 토큰 만료 → `token.pickle` 삭제 후 재로그인 |
| `quotaExceeded` | 하루 쿼터 초과 → 내일 재시도 또는 쿼터 상향 신청 |
| 403 `lockedPrivate` | 위 표의 잠금 정책 — 정상 동작 |

---

## 관련 파일

| 파일 | 역할 |
|---|---|
| `client_secrets.json` | 구글에서 발급받은 앱 인증 정보 (절대 공유 금지) |
| `token.pickle` | 로그인 결과 저장 (자동 갱신됨, 유출 금지) |
| `modules/youtube_upload.py` | 인증 + 업로드 로직 |
